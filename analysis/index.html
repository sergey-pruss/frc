Выводы и gap-анализ

Наш прототип сильнее конкурентов в:

  • Визуальное качество — Apple-level дизайн vs шаблонные решения у 5 из 7 конкурентов
  • SEO-инфраструктура — 245 фильтровых страниц, JSON-LD, уникальный контент (никто из конкурентов так не делает)
  • Фильтрация каталога — полноценный faceted search с live-обновлением (есть только у vsemayki и printbar в упрощённом виде)
  • Контент-маркетинг — блог/журнал (единственные из прямых конкурентов в сегменте)
  • Подарочные механики — сертификаты + Mystery Box (уникально для ниши)
  • Коллекции — отдельная сущность (есть только у Зенита и Третьяковки)
  • Программа лояльности — реализована (есть только у Третьяковки)

Что есть у конкурентов, но пока нет у нас (возможности для развития):

  • Акции/Распродажа — страница со скидками (есть у всех 7 конкурентов)
  • Конструктор / Свой дизайн — кастомизация принтов (vsemayki, printbar)
  • 3D/360° просмотр товара — визуализация на модели (vsemayki, printbar)
  • Отзывы на товары — UGC-контент на карточках
  • Трекинг заказа — «Где мой заказ?» (vsemayki)
  • Сравнение товаров — функция сравнения (kremlin-symbol, yarussia)

Ближайшие бенчмарки по уровню дизайна:

  • shop.fc-zenit.ru — премиальный editorial подход, коллекции как hero, модельная съёмка
  • shop.tretyakovgallery.ru — институциональный мерч с арт-направленностью, смелая типографика

Наш прототип стоит на уровне этих двух лидеров, при этом значительно превосходит прямых конкурентов в нише (ЯRUSSIA, Кремлёвский символ, Русские Витязи) — как по дизайну, так и по техническому SEO.
