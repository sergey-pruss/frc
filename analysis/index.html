Раздел 5

Выводы и gap-анализ

Наш прототип сильнее конкурентов в:

  • Визуальное качество — Apple-level дизайн vs шаблонные решения у большинства конкурентов (Tilda, стандартные CMS)
  • SEO-инфраструктура — 245 фильтровых страниц, JSON-LD, уникальный контент (ни один из 20 конкурентов не реализовал подобное)
  • Фильтрация каталога — полноценный faceted search с live-обновлением (есть только у vsemayki, printbar, printio и Bosco в упрощённом виде)
  • Контент-маркетинг — блог/журнал (единственные в сегменте патриотической одежды; есть только у Великоросса, vsemayki и Bosco)
  • Подарочные механики — сертификаты + Mystery Box (уникально для ниши; сертификаты есть только у музейных магазинов и Зенита)
  • Коллекции — отдельная сущность с навигацией (есть только у премиум-сегмента: Зенит, Bosco, музеи)
  • Программа лояльности — полноценная система (реализована только у Третьяковки из всех 20 конкурентов)

Что есть у конкурентов, но пока нет у нас:

  • Акции / Распродажа — страница со скидками (реализована у 19 из 20 конкурентов)
  • Конструктор / Свой дизайн — кастомизация принтов (vsemayki, printbar, printio)
  • 3D/360° просмотр товара — визуализация на модели (vsemayki, printbar)
  • Отзывы на товары — UGC-контент на карточках товаров
  • Трекинг заказа — «Где мой заказ?» (vsemayki, Атрибутика)
  • Сравнение товаров — функция сравнения (kremlin-symbol, yarussia)

Ближайшие бенчмарки по уровню дизайна:

  • shop.fc-zenit.ru — премиальный editorial подход, коллекции как hero, модельная съёмка
  • shop.tretyakovgallery.ru — институциональный мерч с арт-направленностью, смелая типографика
  • bosco.ru — luxury-позиционирование, спортивное наследие, полноценный e-com

Наш прототип стоит на уровне этих трёх лидеров, при этом значительно превосходит прямых конкурентов в нише (ЯRUSSIA, Кремлёвский символ, Victory Day Shop, Русские Витязи) — как по дизайну, так и по техническому SEO. Из 20 проанализированных сайтов, только 3 (Зенит, Третьяковка, Bosco) приближаются по качеству визуального исполнения.
